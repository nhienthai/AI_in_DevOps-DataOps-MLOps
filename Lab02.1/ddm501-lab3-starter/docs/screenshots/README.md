# Submission screenshots — Lab 3

The lab requires *"screenshots of passing CI workflows"*. This folder holds
them, with a note per image saying what it proves.

Naming follows Lab 2: `NN-surface-what.png`, numbered in the order a reader
should look at them. Keep the numbers — they are how the notes below line up
with the files.

Images 1–3 are from **run #9**, `Merge pull request #5 from
nhienthai/ci-bump-actions`, commit `a13e611` on `main` — the first run after the
GitHub Actions version bump, and the run the README badge reflects.

## Reading images 3 and 4 together

Image 4's static shields.io badges (`tests`, `coverage`, `python`) are text
written into the README — only the first badge, `Lab3 CI`, is generated by
GitHub from real workflow state. Image 3 is where those numbers are actually
*earned*: it is pipeline output, not a claim.

That is the order to present them in — the badge is the summary, the log is the
proof.

## Reproducing

The artifacts behind image 1 are downloadable from the run page:
`coverage-report-py3.10` contains the full `htmlcov/` report, and
`test-results-py3.10` the JUnit XML. Either can be attached to the submission
alongside these images.
